# LocalCanvas V16.0

Galaxy S26 Ultra(12GB RAM, Adreno 840)를 대상으로 **PC·외부 유료 추론 API 없이** 스마트폰 내부에서 `stable-diffusion.cpp` + Vulkan으로 이미지를 생성하는 오프라인 Android 프로젝트입니다.

V16.0 모델 스토어는 검증된 직접 파일 URL만 자동 설치에 사용합니다. Hugging Face에 단일 호환 체크포인트가 확인되지 않는 저장소는 자동 다운로드를 표시하지 않으며, 사용자가 호환 파일을 직접 가져와야 합니다.

- **엔진 호환성**: `ENGINE_API_COMPATIBILITY.md`
- **빌드·실기기 체크리스트**: `INSTALL_AND_DEVICE_CHECKLIST.md`
- **기능 현황·버그·테스트 보고서**: `FEATURE_STATUS.md`, `BUG_TRACKER.md`, `BUILD_REPORT.md`, `TEST_REPORT.md`, `REGRESSION_REPORT.md`
